# CMU 智能教育演进历程

## 四个阶段

### 阶段一：孕育期（1956—1983年）

**起点**：1956年，司马贺等创造"逻辑理论家"（Logic Theorist）——史上第一个 AI 程序，为后续智能教育奠定理论与技术基础。

本阶段核心：产生了利用计算机进行教学的关键思想，为智能导师（Intelligent Tutor）的诞生埋下伏笔。

### 阶段二：萌芽期（1984—1997年）

**关键节点**：
- **1984**：Anderson 等开发 **Lisp 编程导师**和 **GPT 几何证明导师**，并在编程课程上实际应用——CMU 学者首次将 AI 应用于大学教学的重要尝试
- **1994**：**人机交互研究所**（HCII）成立
- **1995**：**自动化学习和发现中心**（CALDS）建成

### 阶段三：成长期（1998—2015年）

OLI（Open Learning Initiative）平台创建，开放在线学习资源。智能导师系统（ITS）从实验室走向大规模课堂应用。

### 阶段四：成熟期（2016年至今）

整合机器学习、数据分析和教育测量，建立基于学习数据的个性化教育体系。OpenSimon 工具包实现跨机构开放共享。

## 时间线摘要

```
1956 → Logic Theorist，AI学科奠基
1984 → 首个智能导师系统上课堂
1994 → 人机交互研究所成立
1995 → 自动化学习和发现中心成立
2016+ → 大数据驱动的个性化教育成熟
```
