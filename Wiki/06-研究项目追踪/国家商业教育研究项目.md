# 国家商业教育研究项目

## 项目基本信息

| 项目 | 内容 |
|------|------|
| 项目名称 | 探索AI时代产教融合路径：提升学生就业竞争力 |
| 级别 | 国家"14五"规划商业教育研究项目 |
| 批准时间 | 2025年9月 |
| 立项时间 | 2023年9月 |
| 主持人 | 方向东（天津城建大学） |
| 身份 | IAEE教育委员会委员；中国会展经济研究会学术委员会委员 |

## 研究框架

### 研究意义
在 AI 时代，高等院校学生就业竞争力受到多方面影响：
- 技能需求变化（AI替代传统岗位）
- 新兴岗位出现（AI专家、数据分析师等）
- 产业结构调整（会展行业数字化转型）

### 核心研究内容
1. AI 时代设计专业学生就业竞争力的影响因素分析
2. 产教融合路径的理论框架与实践机制
3. 会展行业赋能设计教育的具体路径
4. 基于利益相关者的产教融合制度设计（详见[[利益相关者中介模型]]）

### 预期成果
- 学术论文若干篇（核心期刊）
- 政策建议报告
- 课程改革方案

## 关联竞赛成果（2025年）

本项目指导学生团队参与：
- 第20届"中国好创意"国家级一等奖
- 第19届"全国大学生商业精英挑战赛"国家级一等奖
