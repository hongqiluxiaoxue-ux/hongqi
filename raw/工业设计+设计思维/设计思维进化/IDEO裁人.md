
# 1市场上的钱少了
客户量减少，花钱请设计公司越来越少，IDEO原本3亿收入今年为1亿。
# 2[[设计思维]]使设计降维了
设计普及，各个行业对设计越来越在乎，创建项目团队时把建立设计团队或加入设计师纳入考虑范围，倾向花钱建立内部设计团队
# 3AI趋势
IDEO没有在AI领域建立权威

# 设计思维时代终结了
[[设计思维]]：使用者为中心（消费者需求）

# 设计公司劣势：
1.开发趋势周期短，不断推出新，不断测试，找到新发现，多接触使用者，团队内部产品经理和设计师，快速商议出新的解决方案；设计公司要积累到一段时间再沟通；
2.设计公司设计师相比公司内部设计师对产品了解程度会少，公司内部设计师更专注该产品，对技术性能可行性了解，系统组织结构了解，消费者使用历史了解，常年各种细节的累积等，比设计公司的设计师了解更透彻；
3.设计公司不是敏捷开发型，设计时间太短，设计公司费用少认为不值，但现在产品更新速度加快，你如果做了很多前期工作，周期加长，设计出方案，交给开发者生产出来，很有可能推出产品已经落后，使用者需求已经改变，增大商业风险。
4.自由设计师增加，网络上很便宜能找到自由设计师
5.全新的视角，这方面设计公司有优势。
# 对策建议
1.入门最好要有产品公司经验，科技业对设计越来越重视，将来可以进入行业公司，新创公司；
2.要多了解商业，了解产业商业模式，产品思维，营销方法，如何通过设计帮助公司赚钱，其次了解测试，如何通过真实市场的测试，来帮助设计的演化，测试工具，回馈回路了解；
3.找两种类型设计公司，成效导向的公司，产品经验的公司，看如何与公司密切合作；
